# prd-to-prod

A Claude Code plugin that takes an idea, a chat, or a rough PRD to a verified, deployed app:
PRD → feasibility POCs → HLD → frozen acceptance criteria → parallel build → independent verifier.

**Status:** in development. It's built stage by stage alongside a real app, and the design is in [`docs/skill-prd.md`](docs/skill-prd.md).

| Skill | Stage |
|---|---|
| `intake` | 0: project folder, raw inputs, status |
| `design-brief` | The versioned prompt for a Claude Design chat (flows, elements, tokens) |

Install instructions come once the plugin manifest lands.
